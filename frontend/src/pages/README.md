# Pages

This directory contains page-level components that correspond to routes.

## Pages
- `Welcome.tsx` - Landing page
- `Login.tsx` - Login page
- `Register.tsx` - Registration page
- `Dashboard.tsx` - User's group dashboard
- `GroupTasks.tsx` - Task management page
- `Rewards.tsx` - Reward catalog
- `Leaderboard.tsx` - Points leaderboard
- `Profile.tsx` - User profile and statistics
- `GroupSettings.tsx` - Group configuration (admin only)

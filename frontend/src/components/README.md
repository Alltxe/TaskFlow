# Components

This directory contains reusable UI components used throughout the application.

## Structure

- `common/` - Shared components (Button, Input, Modal, etc.)
- `layout/` - Layout components (Header, Sidebar, Footer, AppShell)
- `task/` - Task-related components (TaskCard, TaskForm, TaskList)
- `reward/` - Reward-related components (RewardCard, RewardCatalog)
- `group/` - Group-related components (GroupCard, MemberList)

### 3. **Error Handler** (`lib/core/utils/error_handler.dart`)

#### Новый модуль для обработки ошибок:
- ✅ **Конвертирует технические ошибки в понятные сообщения**
- ✅ **Поддерживает локализацию** (английский и русский)
- ✅ **Два метода отображения**:
  - `showErrorSnackBar()` - показывает Snackbar с ошибкой
  - `showErrorDialog()` - показывает диалог с кнопкой повтора

#### Типы обрабатываемых ошибок:
- `NetworkException` - Нет подключения к интернету
- `TimeoutException` - Превышено время ожидания
- `ServerException` - Ошибка сервера
- `AuthException` - Ошибка авторизации
- `ValidationException` - Ошибка валидации данных
- `NotFoundException` - Ресурс не найден
- `PermissionException` - Доступ запрещен

## Как тестировать

### Подготовка

1. **Запустите бэкенд** на порту 3000:
   ```bash
   cd backend
   npm run dev
   ```

2. **Проверьте доступность GraphQL endpoint**:
   - Откройте в браузере: `http://localhost:3000/graphql`
   - Должен открыться GraphQL Playground

### Сценарии тестирования

#### 1. **Тест подключения к серверу**

**Условие:** Бэкенд запущен и доступен

**Действия:**
1. Запустите приложение на эмуляторе/устройстве
2. Попробуйте войти с валидными учетными данными

**Ожидаемый результат:**
- В логах (Logcat/Console) должны появиться записи:
  ```
  [GraphQL] GraphQL Request: Login
  [GraphQL] Variables: {email: ..., password: ...}
  [GraphQL] Response received in XXXms
  ```
- Успешный вход в приложение

---

#### 2. **Тест: Нет подключения к интернету**

**Действия:**
1. Отключите Wi-Fi/Mobile Data на устройстве/эмуляторе
2. Попробуйте войти в приложение

**Ожидаемый результат:**
- Появится Snackbar с сообщением:
  - 🇷🇺 "Нет подключения к интернету. Проверьте настройки сети."
  - 🇬🇧 "No internet connection. Please check your network settings."
- В логах:

- Кнопка "Войти" снова станет активной

---

#### 3. **Тест: Сервер недоступен**

**Действия:**
1. Остановите бэкенд (Ctrl+C в терминале)
2. Попробуйте войти в приложение

**Ожидаемый результат:**
- Появится Snackbar с сообщением:
  - 🇷🇺 "Превышено время ожидания. Попробуйте еще раз."
  - 🇬🇧 "Request timeout. Please try again."
- Загрузка остановится через ~30 секунд (таймаут)
- Кнопка "Войти" снова станет активной

---

#### 4. **Тест: Неправильные учетные данные**

**Действия:**
1. Введите неправильный email или пароль
2. Нажмите "Войти"

**Ожидаемый результат:**

- Кнопка "Войти" снова станет активной
- В логах:
  ```

  ```

## Решение проблем

### Проблема: "Connection refused" или "Failed host lookup"

**Причина:** Приложение не может подключиться к серверу

**Решение:**
1. **Проверьте, что бэкенд запущен:**
   ```bash
   cd backend
   npm run dev
   ```
   Вы должны увидеть: `Server ready at http://localhost:3000/graphql`

2. **Проверьте правильность URL:**
   - **Android Emulator:** Должен использовать `10.0.2.2:3000`
   - **iOS Simulator:** Должен использовать `localhost:3000`
   - **Real Device:** Должен использовать IP адрес компьютера (например, `192.168.1.100:3000`)

3. **Для реального устройства:**
   - Убедитесь, что устройство и компьютер в одной сети
   - Узнайте IP адрес компьютера:
     - Windows: `ipconfig` (ищите "IPv4 Address")
     - Mac/Linux: `ifconfig` или `ip addr`
   - Запустите приложение с параметром:
     ```bash
     flutter run --dart-define=API_BASE_URL=http://<YOUR_IP>:3000
     ```

4. **Проверьте firewall:**
   - Убедитесь, что порт 3000 открыт в firewall

---

### Проблема: Бесконечная загрузка (не останавливается)

**Причина:** Старая версия кода без таймаутов

**Решение:**
1. Убедитесь, что все изменения применены:
   ```bash
   flutter clean
   flutter pub get
   flutter gen-l10n
   ```

2. Перезапустите приложение:
   ```bash
   flutter run
   ```

3. Если проблема сохраняется, проверьте файл `lib/core/config/graphql_client.dart`:
   - Убедитесь, что есть `_TimeoutHttpClient`
   - Убедитесь, что `request()` метод использует `.timeout()`

---

### Проблема: Ошибка "Unknown error" вместо конкретной

**Причина:** Ошибка не обрабатывается правильно

**Решение:**
1. Проверьте тип исключения в логах
2. Добавьте обработку для этого типа в `ErrorHandler.getUserMessage()`
3. Или обновите бэкенд, чтобы он возвращал более конкретные сообщения об ошибках

---

### Проблема: Localization ошибки (ключи не найдены)

**Причина:** Файлы локализации не сгенерированы

**Решение:**
```bash
flutter gen-l10n
```

Если ошибка сохраняется:
```bash
flutter clean
rm -rf .dart_tool/
flutter pub get
flutter gen-l10n
```
